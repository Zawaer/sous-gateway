# 7-slide pitch decks

Three shorter alternatives to the 12-slide [deck.pdf](../deck.pdf), all 16:9 PDFs with real production screenshots:

- [trust7.pdf](trust7.pdf): trust first. Every slide answers "who decides?": the buyer's mandate, plain code, the buyer's own people, what the product is for.
- [criteria7.pdf](criteria7.pdf): one slide per judging criterion, in weight order (30/20/20/15/15).
- [story7.pdf](story7.pdf): one real production order (the panna cotta case) told step by step.

Eval numbers come from [../../STATUS.md](../../STATUS.md): our own test cases, not a held-out set.
