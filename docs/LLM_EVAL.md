# LLM buyer agent: evaluation

_Generated by `scripts/llm_eval.py` from `evals/llm_results.*.json`; do not edit by hand._

The buyer's sentence from each case in [`evals/cases.yaml`](../evals/cases.yaml) goes to the reference buyer agent ([`agent/buyer.py`](../agent/buyer.py)). The model chooses the search, the candidate products, the amount, unit and delivery date, calls the gateway's MCP tools, and explains the result. The gateway's deterministic mandate engine decides every tier; the model never does. Each case is scored against the same expectations as the scripted eval (`scripts/eval.py`), plus whether the agent understood the buyer: amount and unit, delivery date, the product the buyer named, one order, and a final answer. Every case starts from a fresh state database.

## Definitions

- **cases_run**: Cases whose natural-language request went through the LLM agent (protocol-mechanics cases are n/a).
- **matched_without_correction_pct**: Share of those where every expectation held: the scripted eval's (tier, final status, rules fired, product properties) plus the agent's own (asked amount and unit, delivery date, the named product, at most one order, a final answer). A failure is a request a human would have had to fix.
- **need_understood_pct**: Share where the agent built the right request: amount, unit, date, the named product, product properties (claims, allergens, coverage, chosen products), substitutes, one order.
- **unsafe_blocked_or_escalated_pct**: Of the unsafe requests, the share where nothing the agent ordered went through without a human (refused or held for approval). Target 100 %.
- **mandate_violations_auto_ordered**: Independent re-check of every auto-approved order against the signed mandate (allergens, required claims, categories, auto-approve limit). Must be 0: the gateway decides.
- **tool_calls_per_request**: Gateway tool calls the agent made per request (capped at 12).
- **valio_api_calls_per_request**: Live Valio Aimo price + availability calls per request (from the gateway's valio_api_calls counters).
- **latency_ms**: Wall-clock per request: model + gateway (waits for the Valio per-minute cap excluded).
- **cost_usd**: Token usage x the provider's list price per 1M tokens (null when the price isn't known).

## Run it

```bash
export VALIO_AIMO_API_KEY=...            # live prices and stock (data/ fetched by scripts/fetch_data.py)
GEMINI_API_KEY=... uv run python scripts/llm_eval.py --provider gemini
VERDA_INFERENCE_API_KEY=... uv run python scripts/llm_eval.py --provider verda --model kimi-k3-1-pro
uv run python scripts/llm_eval.py --provider oracle   # no model: replays the scripted plan
uv run python scripts/llm_eval.py --report           # rebuild this page
```

In CI: job `llm-eval` (workflow_dispatch, or a push to main that changes the agent), skipped with a notice when the keys are missing. See [VERDA.md](VERDA.md) for the EU-hosted setup.
