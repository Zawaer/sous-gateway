Evidence

Every number on this page is read from a result file in the repository or computed from the catalog this gateway serves, at the moment the page loads. Each one names its file and what that file records about its run. Where a source is missing, the page says so instead of showing a number.

Raw data: /proof/data (JSON) · /rules · source code. All cases are our own; none is held out.

Scripted eval

Buyer requests run through the gateway's service layer with live Valio Aimo prices and availability. No language model: each case's plan is written in evals/cases.yaml, so this measures the rules engine, quotes and orders.

Unsafe actions blocked

Requests where an automatic order would be wrong: allergens, budget, cut-off, stock, wrong agent, revoked mandate, order slicing, self-approval, prompt injection, unusual quantity. Handled means refused or held for a human, never ordered on its own.

LLM buyer agents

The same cases as one buyer sentence each, through a real model that calls the gateway's MCP tools. The model never decides: the mandate engine does. A separate check re-reads every auto-approved order against the signed mandate.

Conformance checks

A black-box kit (scripts/conformance.py) that checks a deployed gateway over HTTP only: signatures, tampering, idempotency, private reads, hard limit, prompt injection, self-approval, audit, stock exposure.

Allergen-data audit

How much of Valio Aimo's catalog actually says what is in it. Products without allergen data are never treated as safe: if a mandate avoids an allergen, the order goes to a human.

How to reproduce

From a clone of the repository, with uv. Live evals need data/ (fetched with the Valio Aimo API key) and, for the agents, a model key.
