Order cards in the chat

When a buyer's agent works through Sous in a chat that supports MCP Apps (Claude on web, desktop and phone), every quote, order and substitute arrives as a card under the tool call. The card is served by the gateway itself (ui://sous/card.html), shows the mandate's decision rule by rule, and checks the gateway's signature in the chat with the public key that comes in the result. This page is a small chat host of our own, with no model: it draws real demo orders from this gateway with the same card and the same protocol.

Connect Claude yourself: claude mcp add --transport http sous <gateway>/mcp/ (or add it as a custom connector), then ask it to buy something. Get a private sandbox and token at POST /sandbox.
